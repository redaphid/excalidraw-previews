# excalidraw-previews

Build output only. The `Playground preview` workflow in
[redaphid/excalidraw](https://github.com/redaphid/excalidraw) publishes each
pull request's playground to `pr-<number>/` on the `gh-pages` branch and
removes it when the PR closes. Served at https://redaphid.github.io/excalidraw-previews/.
